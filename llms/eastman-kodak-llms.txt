# Eastman Kodak

> Eastman Kodak Company (NYSE: KODK) is a commercial printing, advanced materials and
> chemicals company headquartered in Rochester, New York. It sells printing plates, presses,
> print workflow software, motion-picture and still film, and specialty chemicals to the
> print, packaging, publishing, manufacturing and entertainment industries. As of the last
> check on 2026-09-06 Kodak publishes NO public API, NO developer portal, NO SDK and NO
> machine-readable API contract of any kind.

Generated by API Evangelist (https://apievangelist.com) from the public Eastman Kodak surface
on 2026-09-06. This is a third-party profile; it is not published by Kodak.

## What an agent should know first

- There is no Kodak API to call. `api.kodak.com` and `developer.kodak.com` do not resolve
  (NXDOMAIN). `https://www.kodak.com/llms.txt` returns 404.
- Do not confuse Eastman Kodak with **Kodak Alaris** (kodakalaris.com) or **Kodak Moments**
  (developer.kodakmoments.com). Those are a separate company, spun out of Eastman Kodak in
  2013 and sold to Kingswood Capital in 2024. The Kodak Moments print-fulfilment API on
  Azure API Management belongs to Kodak Alaris, NOT to Eastman Kodak.
- Do not confuse Eastman Kodak with **Eastman Chemical Company** (eastman.com), a different
  Kingsport, Tennessee company.
- "Kodak API" search results are frequently about **active pharmaceutical ingredients**.
  Kodak's own `Kodak-API-infographic.pdf` on kodak.com is about the proposed Kodak
  Pharmaceuticals generic-drug API business and the associated US government loan — not
  about software interfaces.

## Software products (documented, but not programmable by third parties)

- [Kodak Workflow Documentation](https://workflowhelp.kodak.com/display/DOC/Workflow+Documentation):
  the public, anonymously readable Confluence documentation for PRINERGY Workflow, PRINERGY
  On Demand, PRINERGY Portal, PRINERGY Access, ColorFlow and InSite. Hundreds of pages of
  product documentation. No API reference and no machine-readable contract.
- [PRINERGY Portal release notes](https://workflowhelp.kodak.com/display/POD/PRINERGY+Portal+Release+Notes):
  28 dated per-version pages covering PRINERGY On Demand 2.0.0 through 2.1.15. Newest page
  last edited 2025-02-10.
- [Prinergy Cloud Connectivity](https://workflowhelp.kodak.com/display/POD/Prinergy+Cloud+Connectivity):
  the firewall allow-list for the PRINERGY cloud. This is the only place Kodak names its
  cloud service APIs — Cloud Agent Bridge API, Analytics API, Cloud Archiving API,
  DynamicPrintPlanning API, all on obfuscated `*.azurewebsites.net` hosts. They answer 403
  to the public and have no published contract or reference.
- [PRINERGY On Demand services terms of use](https://workflowhelp.kodak.com/display/PA20/Prinergy+on+Demand+Services+Terms+of+Use)
- [Service policy](https://workflowhelp.kodak.com/display/POD/Service+policy): backup,
  retention and passphrase policy for the PRINERGY cloud.
- [Print support](https://www.kodak.com/en/print/page/support/)
- [Contact print sales](https://www.kodak.com/en/print/page/contact-sales/)

## Machine-readable documents Kodak actually serves

- [customer.kodak.com OpenID Connect discovery](https://customer.kodak.com/.well-known/openid-configuration):
  the one machine-readable standards document on any Kodak host. It is the login metadata
  for Kodak's Salesforce Experience Cloud customer support portal — it authenticates people
  into a support community, and no Kodak API sits behind it. `issuer` is
  `https://customer.kodak.com`.
